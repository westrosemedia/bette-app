# BETTE ✨

**Luxury Content Strategist & Sales Tool for Women & Queer Entrepreneurs**

BETTE is a high-converting, AI-powered content strategy platform designed to help women and queer entrepreneurs become unignorable. Built with bold, strategic intelligence and luxury design.

## 🚀 Features

### Core Functionality
- **Daily Content Prompt Generator** - AI-powered content prompts personalized to your brand
- **Smart Scheduler** - Intelligent time management with automatic reminders
- **Brand Vault** - Store and leverage your brand voice and strategy insights
- **Content Vault** - Upload and track usage of brand assets
- **Analytics Dashboard** - Track performance and goals
- **Achievement System** - Gamified progress tracking with badges

### AI Integration
- **Bette's Voice** - Bold, strategic, emotionally intelligent AI assistant
- **Brand Deepener Questions** - Daily strategic questions to learn your brand
- **Personalized Prompts** - Content suggestions based on your goals and tone
- **Smart Scheduling** - Optimized posting times with intelligent reminders

### Design & UX
- **Luxury Aesthetic** - Blush, black, gold, and muted neutrals
- **Conversational Interface** - Feels like talking to your best friend
- **Responsive Design** - Works seamlessly across all devices
- **Smooth Animations** - Elegant transitions and micro-interactions

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS
- **Styling**: Custom luxury design system with Playfair Display & Inter fonts
- **Icons**: Heroicons
- **State Management**: React hooks
- **AI Integration**: OpenAI GPT-4 (planned)
- **Backend**: Node.js/Express or Firebase (planned)
- **Database**: Firestore or MongoDB (planned)

## 🎨 Design System

### Color Palette
- **Blush**: `#ec4899` - Primary brand color
- **Gold**: `#f59e0b` - Accent and success states
- **Charcoal**: `#334155` - Text and neutral elements
- **White/Cream**: Clean backgrounds and cards

### Typography
- **Headlines**: Playfair Display (luxury serif)
- **Body**: Inter (clean sans-serif)

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd bette
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173`
